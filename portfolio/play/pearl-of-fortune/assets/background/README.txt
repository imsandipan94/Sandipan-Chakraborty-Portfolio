BACKGROUND ASSET FOLDER
========================

Drop the final artwork here as:

    background.png

Recommended export size:
    3200 x 6400 px  (4x master asset)

The live game resolution is 800 x 1600 - the game scales
this image down automatically using the existing
GameScaler. No HTML/CSS/JS changes are needed to swap
this file; just replace background.png with a new file
of the same name.

Until background.png is present, the game falls back to
its original placeholder gradient background, so the
project remains playable with this folder empty.
